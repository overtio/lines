# Linedown cheat sheet

lines writes Markdown with a few additions of its own. We call it Linedown.

| Write | Get |
| ----- | --- |
| `**bold**`, `*italic*` | **bold**, *italic* |
| `~~struck~~`, `==highlight==` | ~~struck~~, ==highlight== |
| `#tag`, `#nested/tag` | a tag in the sidebar |
| `- [ ] todo` | a todo |
| `::: card` … `:::` | a card |
| `:::i`, `:::?`, `:::!`, `:::!!!`, `:::^` | a callout |
| `:::! icon=flag`, `:::! icon=none` | a callout with another icon, or none |
| ` ```mermaid ` | a diagram |
| `Key: Value` | a value you can copy |

Everything else is standard Markdown, with GitHub's tables and task lists.
