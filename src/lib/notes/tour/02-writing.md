# Writing in Markdown

Type Markdown and it's formatted as you go. The text stays exactly what you typed, so your notes open in any other app too.

- **Bold** with `**`, *italic* with `*`, ~~strikethrough~~ with `~~`
- <u>Underline</u> with ⌘U, which writes `<u>` and `</u>` around the text
- ==Highlight== with `==`, and `code` with backticks
- A [link](https://example.com): ⌘-click (Ctrl-click) to open it
- GitHub and arXiv links read short, like https://github.com/overtio/lines/issues/1 and https://arxiv.org/abs/1706.03762
- In the apps, `/paper` searches arXiv for a paper by its title, an author or a topic, and links to the one you pick
- Select some text for a small toolbar that does the same

Settings → Editor → Show Markdown chooses how much shows: all of it as written, every mark in sight, or none of it, even where you're writing.

## Arrows and symbols

Type `-` and then `>` and it shows as an arrow: Home -> cabin. The same goes for <-, <->, =>, <=>, <=, >= and !=, in code too. The note keeps the characters you typed: move the cursor onto one to see them. Settings → Editor turns symbols off.

## Marks in the margin

Mark a line with ⌘⇧M (Ctrl+Shift+M) for a bar beside it, as a code editor marks the lines changed. <!-- mark green: done -->
It's a comment at the line's end, `<!-- mark orange: to check -->`, which other apps don't show; move the cursor onto this line to see it. <!-- mark orange: to check -->

## Headings

Start a line with `#`, `##` or `###`. The first line of a note is its title in the list.

## Quotes

> Quotes are for things worth remembering.
> — someone, probably

## Tags

Add a tag anywhere, like #tour/writing, and the note shows under it in the sidebar. Nested tags use a slash. Click a tag to see all its notes (⌘-click to change it). Right-click a tag in the sidebar to rename it everywhere or give it an icon.
