# Lists and todos

- Start a line with `-` for a bullet
- Press Enter to continue the list
  - Tab nests an item under the one above
    - Each level gets its own bullet
  - Shift-Tab moves it back out
- Enter on an empty item ends the list

1. Numbered lists count for you
2. Renumbered as you go
3. And nest the same way

## Todos

- [x] Click a box to tick it
- [ ] ⌘↵ (Ctrl+Enter) turns a line into a todo, or ticks it
- [ ] Notes with open todos show in **Todo** in the sidebar
  - [ ] Todos nest like any list

## Moving things

Hover a line for a grip on its left, and drag it to move the line, a list item with everything under it, a heading, table, code block or card. ⌥↑ and ⌥↓ (Alt) move lines from the keyboard.
