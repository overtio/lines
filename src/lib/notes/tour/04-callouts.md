# Callouts and cards

Callouts make something stand out. Start one with three colons and a sign, and end it with three colons:

:::i
**Info** · `:::i` or `:::info`
:::

:::?
**Question** · `:::?` or `:::question`
:::

:::!
**Warning** · `:::!` or `:::warning`
:::

:::!!!
**Error** · `:::!!!` or `:::error`
:::

:::^
**Decision** · `:::^` or `:::decision`
:::

:::^ icon=sparkles
Click a callout's icon to choose any other, or none at all.
:::

## Cards

A card groups anything: text, lists, tables, code, even other cards. Type `/card`, or select some lines and type `:`.

::: card
### Packing list

- [x] Passport
- [ ] Charger
- [ ] Something to read

:::i
Cards and callouts nest inside each other.
:::
:::

Press Enter on a second empty line at the end of a card to leave it.
