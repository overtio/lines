# Slash commands and shortcuts

Type `/` at the start of a line for a menu of everything you can add. Keep typing to filter it: `/ta` finds Table, `/warn` finds Warning. Tab completes like a shell: `/to` and Tab makes a todo, and `/he` and Tab fills in `/heading`.

| Shortcut | What it does |
| -------- | ------------ |
| ⌘B | Bold |
| ⌘I | Italic |
| ⌘U | Underline |
| ⌘E | Inline code |
| ⌘⇧X | Strikethrough |
| ⌘⇧H | Highlight |
| ⌘↵ | Todo, or tick it |
| ⌥↑ ⌥↓ | Move lines |
| ⌘F | Find in the note |
| ⇧⌘\ | Focus on the note |
| ⌘+ ⌘− | Bigger or smaller text |

On Windows and Linux, use Ctrl for ⌘ and Alt for ⌥.

`/typing` puts in a passage to practice typing on, timed. Try this one: click it, or press ↑ from the line below.

```typing
Sphinx of black quartz, judge my vow! The five boxing wizards jump quickly.
```

:::i
Typing three backticks or three colons adds the closing fence for you. Select lines and type a backtick to put them in a code block, or a colon for a card.
:::
