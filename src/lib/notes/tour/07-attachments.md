# Images and files

Paste an image, drop one onto a note, or type `/image`. It's kept with your notes and saved with them.

![A sunset over the lake](attachment:photo.png)

Click a picture to select it, then Delete removes it.

## Files

Any other file works the same way, or type `/file`. It shows as a card with its name and size; double-click it to open it.

[Budget.csv](attachment:budget.csv)

## Copy values

A line like a label and a value gets a copy button when you hover the value:

**Wi-Fi password:** correct-horse-battery
