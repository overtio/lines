# Slash commands and shortcuts

Type `/` at the start of a line for a menu of everything you can add. Keep typing to filter it: `/ta` finds Table, `/warn` finds Warning.

| Shortcut | What it does |
| -------- | ------------ |
| ⌘B | Bold |
| ⌘I | Italic |
| ⌘E | Inline code |
| ⌘⇧X | Strikethrough |
| ⌘⇧H | Highlight |
| ⌘↵ | Todo, or tick it |
| ⌥↑ ⌥↓ | Move lines |
| ⌘F | Find in the note |
| ⇧⌘\ | Focus on the note |

On Windows and Linux, use Ctrl for ⌘ and Alt for ⌥.

:::i
Typing three backticks or three colons adds the closing fence for you. Select lines and type a backtick to put them in a code block, or a colon for a card.
:::
